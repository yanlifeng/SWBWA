# SWBWA Attribution

SWBWA is derived from BWA, including its BWA-MEM alignment algorithm, by
Heng Li and other upstream contributors. Sunway execution, cross-segment
relocation, CPE memory management, kernel optimizations and distributed I/O
are maintained as part of SWBWA.

The executable, command-line help, SAM program identifier and internal host
archive use the SWBWA name. This branding does not transfer ownership of
inherited code or remove its license obligations. Original copyright and
license notices remain in source files; see also `COPYING`. Third-party
components retain their own notices. Historical changelogs and benchmark
references are preserved as provenance, not relabeled as SWBWA inventions.

The optional upstream `bwakit` post-processing/HLA package is not shipped
with this tree. It is not used by the SWBWA alignment pipeline.
